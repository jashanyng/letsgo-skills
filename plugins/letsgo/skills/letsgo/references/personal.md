# 私人资料设置

在用户要求创建或更新自己的 letsgo 私人资料时执行，不要求私人资料预先存在。遵守[资料组织约定](personal-format.md)和[文件位置](file-paths.md)；确需浏览器时遵守[浏览器入口](browser.md)。

1. 检查 `~/.agents/letsgo/personal/index.md` 及它列出的分类文件。只以用户本轮提供、已有且经用户确认，或用户要求实时只读核验的信息为依据。不请求、读取或保存密码、令牌、私钥正文等凭据；发现疑似凭据值时停止，请用户在本机移除，不把该值输出到对话或候选文件。
2. 没有实质资料时给出精简填写建议：常用远程主机及 SSH 别名、拥有的域名与网络关系、与插件默认值不同的交付路径。说明各项均可选，请用户提供愿意记录的项目。已有资料时只针对本轮需要建议补充，不把分类当必填表。
3. 将确认的资料分类，展示有意义的差异、候选文件路径和待确认内容，请用户确认后写入。用户已在本轮明确授权该批更新时不重复索取批准。未经确认的候选不作为其他技能的事实来源。
4. 候选放在 `~/tmp/personal/`，替换前把受影响文件备份到 `~/backups/personal/`，两处仅当前用户可访问。逐一校验内容与目标路径，以同目录私有临时文件原子替换；分类文件就绪后最后写入 `index.md`。目录仅当前用户可进入，文件仅当前用户可读写；验证失败时保留原文件与备份。
5. 核对索引可读、列出的文件都在目录内且有实质内容、正式内容与确认的候选一致。报告记录范围与尚待确认的信息，不输出私人资料正文。

完成条件：索引只指向有内容的分类文件，资料可按需读取，没有凭据内容或未经确认的推断。
