# 私人资料目录约定

正式目录为当前用户的 `~/.agents/letsgo/personal/`，仅当前用户可进入；文件仅当前用户可读写。入口 `index.md` 只列实际有内容的分类文件，使用目录内相对路径。示例：

```markdown
# letsgo 私人资料索引

> 用户声明的背景信息；易变状态以操作前核验为准。

- 主机与 SSH：hosts.md
- 域名与 DNS：domains.md
- 网络关系：networks.md
- 默认产出位置：outputs.md
```

按需建立分类文件：`hosts.md` 记录身份、用途、SSH 别名、连接定位与各主机的环境背景；`domains.md` 记录域名、用途与管理方式；`networks.md` 记录网络与设备关系；`outputs.md` 只记录用户明确选择、与插件默认值不同的交付路径；服务资料独立且较多时用 `services.md`；无法可靠归类的内容放 `other.md`，等待用户整理。

分类文件用标题区分目标，并标注“用户声明／现场核验／待确认”及日期；核验日期不保证现状仍正确。可写 SSH 别名、用户名与密钥**路径**，不写凭据内容。没有实质分类文件时不创建 `index.md`。
