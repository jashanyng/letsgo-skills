# 代码输出

适用于在对话中输出代码，也适用于生成或修改代码文件。注释只解释非显而易见的意图、约束、安全边界与复杂逻辑，服从目标项目已有规范；保留有效注释，代码变化使注释失真时一并更新。SQL 为迁移目的、事务边界、权限假设与数据影响加注释。

## 命令集

面向用户执行的两条及以上非交互式 POSIX Shell 命令，组织为一次复制粘贴即可执行的命令集，并带必要的中文注释：

```sh
sh <<'COMMANDS'
# 说明本组命令的目的或关键安全边界。
相关 Shell 命令
COMMANDS
```

单条命令、交互式程序、需要 TTY 或密码输入、非 POSIX Shell、无法消除的 heredoc 冲突，或必须逐步验证的高风险操作可以例外。预期结果和停止条件写在命令集注释或运行时输出中。存储为 `.sh` 的脚本使用普通脚本结构，不套用上述包装。

命令集包含上方已展示的文件新增或修改时，紧挨命令集前只写一行：

> 命令集已包含上述修改；已完成的部分只做检查。

执行主机可能混淆时，在这一行前加“在 <主机> 上运行：”。
