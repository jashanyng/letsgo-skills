# 私人资料与远程连接

只在任务确需用户自己的主机、SSH、域名、私人网络或默认产出位置等私人事实时读取。不需要时不检查，也不因资料缺失而停下。

## 读取私人资料

入口是 `~/.agents/letsgo/personal/index.md`，它以 `personal/` 内的相对路径列出实际存在的分类文件。只读本次所需的分类：

| 任务涉及 | 读取 |
| --- | --- |
| SSH、远程主机、NAS、VPS 或服务 | `hosts.md`；涉及服务时再读 `services.md`（若存在） |
| 域名、DNS、证书或公网入口 | `domains.md`；关联主机时再读 `hosts.md` |
| 家庭、公司或其他私人网络 | `networks.md`；关联设备时再读 `hosts.md` |
| 脚本、笔记或其他交付物的默认路径 | `outputs.md`（若存在） |

- 索引缺失、无效，或没有本次目标的记录时，只暂停依赖它的部分，提示用户可直接说“更新我的 letsgo 私人资料：……”来配置；其他工作继续。不按相似名称猜测。
- 资料是用户声明的背景，主机和服务的易变状态在操作前实时只读核验。记录与现场冲突且影响目标身份或高影响操作时先澄清；可安全继续的偏差报告证据并提醒用户更新。只有[私人资料设置](personal.md)流程改写私人资料，且写入前经用户确认。
- 可使用 SSH 别名、用户名与密钥文件路径；不读取、回显或保存私钥正文、密码、令牌、Cookie 等凭据。

## 远程命令

用户本轮指定的目标和通道优先；否则按 `hosts.md` 确定目标与已登记的 SSH 别名。连接前核对实际目标，不临时建立未知连接。连接失败时可改用其他已登记通道；命令已到达目标后失败，不换通道重跑。全部通道不可用时，报告目标、尝试过的通道和失败原因，等待用户提供连接信息。

## 用户语境中的概念

- **科学上网**：通过境外 VPS 提供的 VPN 或代理节点访问受限的境外服务，通常期望国内直连、境外走代理。这个称呼不证明某台主机已部署或分流正确。
- **webshare／住宅 IP**：面向区域限制或严格代理识别服务的住宅出口方案，不预设实际供应商。目标是让访问流量、DNS 和 WebRTC 都走预期出口，按实际客户端与链路验证 DNS、WebRTC、IPv4／IPv6 出口；仅启用 DoH 不等于没有 DNS 泄漏。

具体节点、供应商、域名、账号与网络拓扑只来自私人资料和实时核验。
