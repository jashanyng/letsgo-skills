# letsgo: skill walk

遵守[语言约定](../letsgo/references/language.md)；其他规则按[letsgo 规则入口](../letsgo/SKILL.md)命中时读取。

引导用户采用指定的 skill(s) 来实现需求，在达成目标的同时帮助用户掌握这些 skill 的运用方法。

## 识别前提

调用时需识别两个要素：

1. **需求**：用户要实现的目标
2. **指定的 skill(s)**：用户希望采用的一个或多个技能

如果任一缺失，询问用户补充。

## 检查可用性

指定的每个 skill 必须在当前 AI 客户端中已生效（已安装且可读取其 `SKILL.md`）。未生效的 skill 提示用户先安装，不凭记忆执行。

## 评估与报告

读取指定 skill(s) 的 `SKILL.md`，结合需求现场评估：

1. **推荐组合**：从指定的 skill(s) 中筛选出适合当前需求的 skill 或最小必要组合，说明每个的职责。
2. **执行流程**：
   - 若为多个 skill 的组合：说明执行顺序，标注哪些会自动触发、哪些需要用户显式调用
   - 若为单个 skill：说明它是隐式触发还是显式调用
3. **提示词**：给出简洁的代码块提示词，便于用户点击复制、粘贴到会话中发送

推荐说明保持简洁，提示词必须精炼。

## 执行节奏

- **必须显式调用的 skill** 或 **现场评估建议用户发出对话时**：停下来，给出代码块提示词
- **skill 内部能自动路由的隐式 skill**，且适合现场任务路由触发的：直接继续，不停下
- 同一会话多轮对话，每次答复完毕需要用户操作时，给出相应的简洁代码块提示词
- 需求的全部任务执行完毕时，输出总结报告

## 提示词格式

代码块提示词直接以目标 skill 命令开头（Antigravity 与 Claude Code 为 `/<skill>`，Codex 为 `$<skill>`），必要时后接一句话上下文。在同一会话继续时不前置 `letsgo:skill-walk`。
