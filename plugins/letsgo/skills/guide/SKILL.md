# letsgo: guide

遵守[语言约定](../letsgo/references/language.md)；其他规则按[letsgo 规则入口](../letsgo/SKILL.md)命中时读取。

按当前需求在**能力范围**内现场评估适合的**能力**（skill、MCP 与内置工具的统称），逐步推进达成目标并呈现用法要点。

## 1. 识别需求与能力范围

1. **需求**：未给出目标且上下文无可推断任务时，只问一句请用户补充需求。
2. **能力范围**（本次优先考虑的能力集合，按以下优先级锁定）：
   - 本次消息明确指定的范围（“全部能力”“全部”或“all”同义，均指当前宿主支持的全部能力）；
   - 上下文明确表达“用 X 来做”的指定（仅提及或讨论某能力不算指定）；
   - 默认取“全部能力”。
3. **基础与范围外能力**：读写文件、终端、搜索等基础内置能力始终可用；范围外已安装的 skill 或 MCP 明显更适合当前需求时直接采用，并在过程说明行加注`（范围外）`。

## 2. 两段低耗筛选

仅基于当前会话实时上下文筛选，同会话已评估结论直接复用，保持无状态而不创建持久化能力索引文件。

1. **初筛**：仅看会话已载入能力清单的名称与描述做内部筛选，回复中只输出选定结论，不罗列完整清单。
2. **深读**：仅对入围候选读取 `SKILL.md` 或 MCP Schema，以实读定义为准、不凭记忆执行；单轮一般不超过 3 个，确需更多时简短说明原因。
3. **未生效处理**：指定范围内某能力在当前宿主未生效（未安装或未启用）时，提示未生效并转入下方“缺少必要支持”处理。

## 3. 执行节奏与提示词

按筛选结果并实读 `SKILL.md` 元数据或 MCP Schema 确定触发方式后，按以下规则推进：

- **极简说明行与 6 类触发标签**：每次采用能力时输出极简一行（范围内：`【guide】<能力>（<触发标签>）—— <极简用途>`；范围外：`【guide】<能力>（<触发标签>·范围外）—— <极简用途>`），`<触发标签>` 固定取以下 6 类之一：
  - `可隐式`：普通技能（未设 `disable-model-invocation: true` 且未设 `user-invocable: false`），自然语言即可命中，也可显式点名；
  - `仅显式`：设了 `disable-model-invocation: true`，必须以 `/<skill>`（Codex `$<skill>`）显式调用；
  - `仅隐式`：设了 `user-invocable: false`，菜单隐藏，仅自然语言命中；
  - `内部路由`：由上游技能内部串联拉起，或经调用 `guide` 时显式授权在会话内代跑，无需单独调用；
  - `MCP 直调`：已挂载的 MCP 工具调用；
  - `内置工具`：宿主原生工具或原生机制。
- **直接推进与停下接力规则**：
  - **不停下直接推进时**（`可隐式`、`仅隐式`、`内部路由`、`MCP 直调`、`内置工具` 且当前无需用户确认或授权）：直接执行并只输出上述极简一行说明，不在过程正文中间插播参考示范代码块，避免与“需立即复制发送的接力代码块”混淆。
  - **任何停下等待用户操作、授权、确认或新开会话的节点**（不论命中 `仅显式` 技能，还是因方案确认／授权要求而停下且下一步将用 `可隐式` 技能或直接执行）：**必须给出包裹在代码块中的极简接力提示词**，方便直接复制发送：
    - 命中 `仅显式` 技能默认停下时：给出以目标原生命令开头的 1 行极简提示词（Claude Code 与 Antigravity 为 `/<skill>`，Codex 为 `$<skill>`，同会话继续时不前置 `letsgo:guide`，只保留最小上下文指针）；
    - 同会话因确认或授权停下（后续为 `可隐式` 技能或直接执行）时：代码块只放当前马上可发送的极简指令（例如 `授权实施`，必要防漏命中时最多写成 `授权实施，用 <skill> 执行`），不塞长篇上下文或跨会话示范；
    - 仅当用户在调用 `guide` 时明确授权代跑显式技能（如“显式技能可代为执行”），才在本会话内读取其 `SKILL.md` 直接执行并标为 `（内部路由）`；涉及发布、推送、删除或覆盖等操作仍遵守[变更安全](../letsgo/references/change-safety.md)等规则。
- **无匹配扩展能力但当前客户端可直接实施**：输出一行 `【guide】无匹配能力，直接实施 —— <原因>`；是否停下由当前现场需求决定，`guide` 不干预；若因需求自身门禁停下等待授权，同样附包裹在代码块中的极简接力提示词。
- **缺少必要支持**：当前能力均不足以完成目标或指定能力未生效且无可靠替代时，优先检索宿主自带市场（Antigravity 使用 `search_marketplace`，Claude Code 与 Codex 查询插件市场），已安装 `find-skills` 时配合使用，必要时联网检索；只报告、不安装——列明名称、用途、安装方式及不添加时的替代做法，停下等待用户决定。

## 4. 收尾

全部任务完成后，输出一段**简洁、略宽松**的复盘总结：列出本次使用的各项能力、触发标签与核心用法要点，并为后续脱离 `guide` 独立复用给出极简参考提示词（包裹在代码块中）。
