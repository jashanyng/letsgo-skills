# Triage 标签映射

工程技能使用五个标准分流（triage）角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签          | 含义                         |
| -------------------------- | ------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`      | 需要维护者评估此 Issue       |
| `needs-info`               | `needs-info`        | 等待提交者补充更多信息       |
| `ready-for-agent`          | `ready-for-agent`   | 规格已明确，可交由 Agent 处理 |
| `ready-for-human`          | `ready-for-human`   | 需要人工实现                 |
| `wontfix`                  | `wontfix`           | 不予处理                     |

当技能提到某个角色（例如“打上可由 Agent 自动处理的 triage 标签”）时，请使用上表中对应的实际标签字符串。

如需改用其他标签名，可直接修改“本仓库标签”一列以匹配实际词汇表。
