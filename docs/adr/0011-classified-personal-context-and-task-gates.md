# 私人资料分类与按需门禁

2026-11-07 决定把当前用户的私人资料从单个 `~/.agents/letsgo/personal.md` 调整为 `~/.agents/letsgo/personal/` 分类目录：`index.md` 只指向实际有内容的分类文件，供技能按任务需要读取。本决策取代 [ADR-0008](0008-plugin-runtime-and-personal-context.md) 的单文件资料位置，以及其中“未配置私人资料则所有显式技能停止”的门禁；[ADR-0010](0010-no-hooks-skills-carry-rules.md) 的无事件钩子规则继续有效。

单文件容易让无关私人事实进入一次任务的上下文；全局门禁也会阻止不依赖私产的讲解或文件任务。分类索引让用户自己维护可读资料，并让技能在确需私人事实时才检查和读取。索引须有至少一条有效的目录内相对路径，目标文件可读且有实质内容；只有这样才表示用户已提供私人资料。缺少本次目标的信息仍需澄清，不能从索引存在推断资料完整。

## 取舍与后果

- 无需私产的技能可直接运行；确需私产时，索引缺失或无效会使依赖该事实的部分暂停。`letsgo:personal` 在显式调用后建议值得填写的类别，且不要求每类齐全。
- 旧版单文件在新目录建好并验证后仍可暂存，供尚未更新的客户端使用。两端插件更新且新版入口可用后才将旧文件移到私有备份。其他用户可在首次显式调用 `personal` 时迁移；插件不通过安装脚本或钩子自动迁移。
- 用户本轮指定的交付路径优先；分类资料中明确记录的产出路径其次；插件默认路径最后。未记录偏好时不改变原默认值。
- 插件包只包含分类规则、示例和流程，不包含用户的任何私人资产事实或凭据。
